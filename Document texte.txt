 ### 1. L'importation de la bibliothèque

  Tout en haut du fichier HTML, on importe la version "Viewer" (visualiseur en lecture seule, sans les outils de modification)
  de la librairie depuis un CDN :
    <script src="https://unpkg.com/bpmn-js@11.5.0/dist/bpmn-viewer.development.js"></script>
  ### 2. L'initialisation du moteur

  Dans le code JavaScript, on crée une instance du visualiseur en lui indiquant dans quelle "boîte" (div) il doit dessiner le
  schéma :

    const viewer = new BpmnJS({ 
        container: '#canvas-container', 
        width: '100%', 
        height: '100%' 
    });

  ### 3. La "Magie" du rendu (La lecture du XML)

  Quand vous sélectionnez un fichier XML, le script lit son contenu sous forme de texte brut. Ensuite, on ordonne au viewer de
  l'interpréter :
    await viewer.importXML(xmlString);

  Que fait la librairie sous le capot à cet instant ?

  • Le XML BPMN contient deux grandes parties : la logique (les tâches, les id, les assignations) et une balise spéciale nommée
  <bpmndi:BPMNDiagram>.
  • Cette balise contient les coordonnées mathématiques (X, Y, hauteur, largeur) de chaque boîte et chaque flèche.
  • bpmn-js lit ces coordonnées et génère instantanément un immense élément <svg> (une image vectorielle) avec des formes
  géométriques qu'il injecte dans notre #canvas-container.

  ### 4. Le Recadrage automatique (Zoom)

  Une fois le SVG dessiné, il peut être minuscule ou gigantesque par rapport à l'écran. On utilise l'API interne du canvas de
  bpmn-js pour lui dire : "Calcule la taille de tout ce que tu viens de dessiner, et ajuste le zoom pour que ça rentre
  parfaitement dans l'écran" :

    viewer.get('canvas').zoom('fit-viewport', 'auto');

  ### 5. La particularité pour le PDF (Notre astuce)

  Comme bpmn-js utilise des techniques complexes de zoom interactif (matrice de transformation SVG), l'imprimante du navigateur
  n'arrive pas à l'imprimer correctement. C'est pour ça qu'on utilise une fonction spéciale :

    const { svg } = await viewer.saveSVG({ format: true });

  Cette fonction demande au moteur : "Génère-moi le code brut de l'image SVG statique, sans les couches interactives". On cache
  ce SVG parfait dans la page (#print-svg-container), et on ne le dévoile qu'au moment précis où vous cliquez sur "Imprimer" !

  En résumé : Le XML contient les coordonnées -> bpmn-js les traduit en dessin SVG -> on ajuste la caméra dessus.
