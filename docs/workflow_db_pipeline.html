🗄️ Structure de la Table incidents

Cartographie exacte des colonnes affectées lors du changement d'état d'un incident.

Colonne SQL Type SQL Attribut / Constraint Rôle lors de la modification
id BIGSERIAL PRIMARY KEY Identifiant unique de l'incident
status VARCHAR(255) NOT NULL Modifié avec le nouvel état (ex: 'En cours')
updated_at TIMESTAMP NOT NULL Mis à jour automatiquement via @PreUpdate
workflow_id BIGINT FOREIGN KEY Référence le schéma du workflow rattaché
author_id BIGINT FOREIGN KEY Auteur initial de la déclaration
