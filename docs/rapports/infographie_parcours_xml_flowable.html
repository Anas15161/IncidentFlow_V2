1.1 Conception Visuelle Port 8082
L'analyste dessine le workflow des incidents :
• Événement départ : StartEvent
• Tâches humaines : UserTask
• Flèches orientées : SequenceFlow
1.2 Document XML BPMN 2.0 OMG Standard
<!-- Fichier généré --> <process id="incidentWorkflow"> <userTask id="taskNouveau" name="Nouveau"/> <userTask id="taskAssigne" name="Assigné"/> <userTask id="taskEnCours" name="En cours"/> <userTask id="taskResolu" name="Résolu"/> <sequenceFlow sourceRef="taskEnCours" targetRef="taskResolu"/> </process>
💡 Avantage : Aucune logique de transition n'est codée en dur dans le code Java. Le dessin XML devient le contrat d'exécution.
